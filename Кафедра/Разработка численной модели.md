## 1.2 Подключенные библиотеки:

``` cpp
#include <cmath>
#include <cstdlib>
#include <iostream>
```

- `cmath` — математика: `std::sqrt`, `std::pow`, `std::abs`, `std::floor` и так далее.
- `cstdlib` — общие утилиты: `exit`, `rand`, `srand`, `remove` и прочее.
- `iostream` — вывод в консоль через `std::cout`, `std::cerr`.

``` cpp
#include "epot_bicgstabsolver.hpp"
```

- Он работает поверх постановки задачи Пуассона, которую IBSimu строит по геометрии и граничным условиям; при этом может решать не только линейную вакуумную задачу, но и нелинейные плазменные варианты через методы Newton-Raphson.
- Физический смысл здесь такой: именно этот объект будет находить потенциал ϕ\phiϕ в расчётной области из уравнения Пуассона с учётом геометрии, зарядовой плотности и граничных условий.
```cpp 
#include "geometry.hpp"
```

Через `Geometry` задаются:

- размер области;
- шаг сетки;
- тип геометрии (`MODE_1D`, `MODE_2D`, `MODE_3D`, `MODE_CYL`);
- границы;
- твёрдые тела-электроды.

`Geometry` — это каркас всей задачи. Он определяет, **где именно** решается поле и **какие объекты** есть внутри области. В tutorial `plasmacyl` это видно напрямую: сначала создают `Geometry geom(...)`, потом через `set_solid(...)` и `set_boundary(...)` задают электроды и границы, а затем вызывают `geom.build_mesh()`.

```cpp
#include "func_solid.hpp"
```

- По официальному tutorial `plasmacyl` он используется, когда геометрию электрода задают не через CAD/DXF, а через булеву функцию вида `bool solid1(double x, double y, double z)`. Затем создаётся объект: `Solid *s1 = new FuncSolid( solid1 );`
- Физически это значит: форма электрода или стенки задаётся аналитически, условием «точка внутри тела или нет». Это очень полезно для первых моделей, когда ты хочешь быстро описать щели, пластины, фаски, прямоугольные блоки, апертуры, не импортируя CAD.
